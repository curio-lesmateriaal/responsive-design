Doe-opdrachten

Bij deze opdrachten ga je de CSS en HTML aanpassen. Voeg nieuwe code toe, test in de browser en maak de site responsiever!

Opdracht 1: Extra breakpoint toevoegen

Voeg een nieuw breakpoint toe voor tablets (bijv. 900px).

  • Zet het .grid op 2 kolommen bij schermen ≤900px en >700px.
  • Verklein de .hero h1 font-size licht bij ≤900px (bijv. 36px).
  • Test in de browser door venster te schalen.

Opdracht 2: Mobiele navigatie verbeteren

Maak de navigatie compacter en gebruiksvriendelijker op kleine schermen.

  • Verminder de padding van .nav op schermen ≤700px.
  • Maak de .btn touchvriendelijk met een minimum hoogte van 44px op mobiel.
  • Zorg dat de navigatie links goed klikbaar zijn op touch devices.

Opdracht 3: Responsive afbeeldingen

Voeg een voorbeeldafbeelding toe en maak die schaalbaar.

  • Voeg in index.html een afbeelding toe in een artikel card.
  • Maak een CSS-regel voor img met max-width: 100% en height: auto.
  • Controleer dat er geen horizontale scroll ontstaat op mobiel.

Opdracht 4: Nieuwe badge variant

Voeg een nieuwe badge variant toe met een andere kleur.

  • Maak een nieuwe class .badge.info met een paarse of cyaan kleur.
  • Gebruik dezelfde structuur als de bestaande badge varianten.
  • Test de badge door deze toe te voegen aan een artikel card.

Opdracht 5: Sidebar sticky gedrag

Pas het sticky gedrag van de sidebar aan.

  • Zorg dat de sidebar sticky blijft tijdens scrollen (controleer of dit al werkt).
  • Pas de top waarde aan zodat er ruimte is onder de header.
  • Zorg dat op mobiel de sidebar niet sticky is (dit zou al moeten werken).

Opdracht 6: Font sizes responsive maken

Maak de font-sizes nog responsiever met clamp() of viewport units.

  • Gebruik clamp() voor .hero h1 om tussen een minimum en maximum te blijven.
  • Bijvoorbeeld: font-size: clamp(28px, 4vw, 48px)
  • Test hoe de tekst schaalt bij verschillende schermgroottes.

Finale Opdracht

Deze finale opdracht combineert alles wat je hebt geleerd over responsive web design. Maak een volledig nieuwe, responsive contact pagina.

🎯 Finale Opdracht: Complete Responsive Contact Pagina

Deze finale opdracht combineert alles wat je hebt geleerd. Maak een volledig nieuwe, responsive contact pagina.

Opdracht:

Maak een nieuwe HTML-pagina contact.html met een volledig responsive contactformulier en contactinformatie.

Vereisten:

  • HTML Structuur: Maak een nieuwe contact.html met dezelfde header en footer als index.html
  • Grid Layout: Gebruik CSS Grid om de pagina te verdelen in twee kolommen (formulier links, contactinfo rechts) op desktop
  • Responsive Breakpoints:
    • Desktop (>900px): 2 kolommen naast elkaar
    • Tablet (700px-900px): 2 kolommen, maar compacter
    • Mobiel (≤700px): 1 kolom, stack verticaal
  • Contactformulier: Maak een formulier met velden voor naam, email, onderwerp en bericht. Styling consistent met de rest van de site
  • Contact Informatie: Voeg een sectie toe met adres, telefoon, email (gebruik icons of emoji's)
  • Responsive Typography: Gebruik clamp() voor ten minste één heading (bijv. de hoofdtitel)
  • Buttons: Maak een submit button die responsive is (minimaal 44px hoog op mobiel)
  • Images: Voeg eventueel een contactafbeelding toe die responsive schaalt
  • Spacing: Gebruik consistente padding en margins die aanpassen op verschillende schermgroottes

✅ Checklist voor voltooiing:

  • Pagina werkt op desktop, tablet en mobiel
  • Geen horizontale scroll op welke schermgrootte dan ook
  • Formulier velden zijn goed klikbaar op touch devices
  • Tekst is leesbaar op alle schermgroottes
  • Layout verandert logisch bij breakpoints
  • Styling is consistent met de rest van de website

💡 Extra uitdaging (optioneel):

  • Voeg een interactieve kaart toe (bijv. Google Maps iframe) die responsive is
  • Maak een "Stuur bericht" animatie met CSS transitions
  • Voeg form validatie toe met HTML5 required attributes
  • Maak de header sticky en pas de sidebar/padding aan bij scrollen
